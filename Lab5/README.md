# Лабораторная работа № 5

Вариант 5: с клавиатуры вводится строка S, состоящая из букв и цифр;
из букв строки S сформировать строку S1, из цифр — S2.

Обработка строки — ассемблерная вставка `__asm` в функции `get_result`,
ввод и вывод на C++.

## Алгоритм

| Регистр | Назначение |
|---|---|
| `ESI` | текущий символ исходной строки, работает с `lodsb` |
| `EDI` | текущая позиция в строке S1, работает с `stosb` |
| `EBX` | текущая позиция в строке S2 |
| `ECX` | счётчик цикла, длина строки |
| `AL` | прочитанный символ |

`lodsb` берёт байт по адресу `ESI` в `AL` и сдвигает `ESI` на 1,
`stosb` кладёт `AL` по адресу `EDI` и сдвигает `EDI` на 1.

Символ классифицируется сравнением с границами диапазонов ASCII:
`'0'..'9'` — цифра, `'A'..'Z'` и `'a'..'z'` — буква, остальное пропускается.

Цифры пишутся через `mov [ebx], al` и `inc ebx`, потому что `stosb` умеет
работать только с `EDI`, а приёмника два.

В конце обе строки закрываются нулём. Пустая строка отсекается проверкой
`cmp ecx, 0` до цикла: `loop` при нулевом `ECX` ушёл бы на 4 миллиарда
повторений.

## Сборка

Платформа **x86**, Ctrl+F5. MASM32 SDK не нужен, это обычный проект C++.

Вставки `__asm` компилятор принимает только под x86.
