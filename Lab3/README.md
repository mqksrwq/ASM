# Лабораторная работа № 3

Вариант 5: дано целое число `m`. Получить наибольшее `k`, при котором `2*k` меньше `m`.

Переменные `m`, `k` имеют формат слова (`DW`, знаковое, -32768..32767).

## Сборка в Visual Studio

1. Нужен MASM32 SDK в `C:\masm32` (как в лабах 1–2).
2. Сделать Lab3 запускаемым проектом (ПКМ → Set as Startup Project).
3. Платформа — **x86**, Ctrl+F5.

## Алгоритм

Цикл со счётчиком: количество повторений заносится в `ECX`, команда `loop`
уменьшает его на единицу и повторяет тело, пока `ECX` не станет нулём.
`EBX` хранит `k`, `EDX` — значение `m`.

Два случая разделены проверкой знака `m`:

| Ветка | Условие | Что делает |
|---|---|---|
| `Up` | `m > 0` | проверяет кандидата `k+1`, пока `2*(k+1) < m` — увеличивает `k` |
| `Down` | `m <= 0` | уменьшает `k`, пока не выполнится `2*k < m` |

Выход из цикла до исчерпания `ECX` делает условный переход на метку `Ready`.
Счётчик задаёт верхнюю границу числа повторений: `m` для ветки `Up`
и `|m| + 2` для ветки `Down` — этого заведомо хватает.

`ECX` здесь использовать можно, потому что внутри цикла нет вызовов
процедур masm32: ввод выполнен до цикла, вывод — после.

`2*k` считается в 32-битных регистрах: при `m = 32767` значение `2*k`
доходит до 32768 и в слово не помещается.

## Примеры

| m | k |
|---|---|
| 10 | 4 |
| 11 | 5 |
| 1 | 0 |
| 0 | -1 |
| -5 | -3 |
