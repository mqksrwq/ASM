# Лабораторная работа № 2, оптимизированный вариант

Задание то же, что в Lab2: даны три числа, выбрать принадлежащие интервалу 1..10.

Отличие от Lab2: переменных в памяти нет совсем, значения живут в регистрах.

| Значение | Регистр |
|---|---|
| a | `ECX` |
| b | `EDX` |
| c | `EAX` |
| счётчик | `EBX` |

## Про push и pop

По соглашению `stdcall` процедура обязана сохранить `EBX`, `ESI`, `EDI`, `EBP`,
а `EAX`, `ECX`, `EDX` может использовать свободно. `EAX` вдобавок возвращает
результат.

Поэтому `EBX` под счётчик взят без всякой защиты, а `EAX`, `ECX`, `EDX`
приходится сохранять на стеке вокруг каждого вызова:

```asm
    push EAX
    push ECX
    push EDX
    Invoke StdOut, addr resultMsg
    pop EDX
    pop ECX
    pop EAX
```

Всего таких сохранений 15 пар. Если вместо `ECX`, `EDX`, `EAX` взять
`ESI`, `EDI`, `EBP`, они не нужны вообще: эти регистры вызовы не портят.

## Сборка

Платформа x86, Ctrl+F5. Нужен MASM32 SDK в `C:\masm32`.
