# Лабораторная работа № 1

Вариант 5: `X = 5*a + c*b`

Переменные `a`, `b`, `c`, `x` имеют формат слова (`DW`, знаковое, -32768..32767).

## Требования

Нужен MASM32 SDK, установленный в `C:\masm32` (https://www.masm32.com).
Из него берутся `masm32.inc`, `kernel32.inc` и процедуры
`StdOut`, `StdIn`, `StripLF`, `atol`, `dwtoa`.

`windows.inc` намеренно не подключается: он не совместим с современным `ml.exe`
(`A2042: statement too complex`), а для этой программы не нужен.

## Сборка в Visual Studio

1. Платформа — **x86** (Win32).
2. Ctrl+F5.

В настройках проекта уже прописано:
- сборка `main.asm` через masm build customization;
- точка входа `start` (CRT не используется);
- `/SAFESEH:NO`.

## Алгоритм

| Шаг | Команда | Действие |
|---|---|---|
| 1 | `mov AX, a` | AX = a |
| 2 | `mov BX, 5` / `imul BX` | DX:AX = 5*a |
| 3 | `mov CX, AX` | CX = 5*a |
| 4 | `mov AX, ces` | AX = c |
| 5 | `imul b` | DX:AX = c*b |
| 6 | `add AX, CX` | AX = 5*a + c*b |
| 7 | `mov x, AX` | сохранение результата |

`imul` с одним операндом: `DX:AX = AX * операнд`. Результат — слово, поэтому
используется только младшая половина `AX`.

## Об имени переменной c

`c` — зарезервированное слово ассемблера (тип языка C, как в `.model flat, C`),
поэтому переменная названа `ces`.

## Пример

```
Input a: 3
Input b: 4
Input c: 7

X = 5*a + c*b = 43
```
