# Лабораторная работа № 6

Вариант 5: дано X (DWORD). Чётные разряды задать единицами,
полученное значение разделить на 8, поменять местами правую и левую части.

## Алгоритм

| Шаг | Команда | Действие |
|---|---|---|
| 1 | `or EDX, 55555555h` | единицы в разряды 0, 2, 4, ... 30 |
| 2 | `shr EDX, 3` | деление на 8 сдвигом, без команды деления |
| 3 | `ror EDX, 16` | обмен младшего и старшего слов |

Маска `55555555h` — это `0101...0101` в двоичном виде, единицы стоят
в чётных разрядах при нумерации с нуля.

Подпрограмма `ShowBin` печатает число в двоичном виде: 32 раза сдвигает
`EDX` влево, старший бит попадает в флаг переноса, а `adc AL, 0`
превращает его в символ `'0'` или `'1'`.

## Пример

Для X = 100:

```
X              = 00000000000000000000000001100100
Even bits set  = 01010101010101010101010101110101
Divided by 8   = 00001010101010101010101010101110
Halves swapped = 10101010101011100000101010101010
```

## Сборка

Платформа x86, Ctrl+F5. Нужен MASM32 SDK в `C:\masm32`.
