# Лабораторная работа № 2

Вариант 5: даны три числа — выбрать из них те, которые принадлежат интервалу от 1 до 10.

Переменные `a`, `b`, `c` имеют формат слова (`DW`, знаковое, -32768..32767).

## Требования

Нужен MASM32 SDK, установленный в `C:\masm32` (https://www.masm32.com).
Из него берутся `masm32.inc`, `kernel32.inc` и процедуры
`StdOut`, `StdIn`, `StripLF`, `atol`, `dwtoa`.

`windows.inc` намеренно не подключается: он не совместим с современным `ml.exe`
(`A2042: statement too complex`), а для этой программы не нужен.

## Сборка в Visual Studio

1. Платформа — **x86** (Win32).
2. Ctrl+F5.

В настройках проекта уже прописано:
- сборка `main.asm` через masm build customization;
- точка входа `start` (CRT не используется);
- `/SAFESEH:NO`.

## Алгоритм

Проверка интервала для каждого числа — двойное сравнение с переходом на метку пропуска:

| Шаг | Команда | Действие |
|---|---|---|
| 1 | `mov AX, a` | AX = a |
| 2 | `cmp AX, 1` / `jl SkipA` | если a < 1 — пропустить вывод |
| 3 | `cmp AX, 10` / `jg SkipA` | если a > 10 — пропустить вывод |
| 4 | `movsx EAX, a` / `dwtoa` | число в строку |
| 5 | `StdOut` | вывод имени и значения |
| 6 | `inc cnt` | счётчик подошедших чисел |

`jl` и `jg` — знаковые переходы, так как переменные знаковые.
`cnt` в конце сравнивается с нулём: если ни одно число не попало в интервал,
выводится `none`.

## Об имени переменной c

`c` — зарезервированное слово ассемблера (тип языка C, как в `.model flat, C`),
поэтому переменная названа `ces`.

## Пример

```
Input a: 5
Input b: 15
Input c: 0

Numbers from 1 to 10:
a = 5
```
