# Лабораторная работа № 6

Вариант 5: дано X (DWORD). Чётные разряды задать единицами,
полученное значение разделить на 8, поменять местами правую и левую части.

Обработка — ассемблерная вставка `__asm` в функции `get_result`,
ввод и вывод на C++.

## Алгоритм

| Шаг | Команда | Действие |
|---|---|---|
| 1 | `or eax, 55555555h` | единицы в разряды 0, 2, 4, ... 30 |
| 2 | `shr eax, 3` | деление на 8 сдвигом, без команды деления |
| 3 | `ror eax, 16` | обмен младшего и старшего слов |

Маска `55555555h` — это `0101...0101` в двоичном виде, единицы стоят
в чётных разрядах при нумерации с нуля.

## Вывод по этапам

Каждый шаг вынесен в свою функцию со своей вставкой, `main` печатает число
после каждого вызова — в двоичном виде и в десятичном.

## Пример

Для X = 100:

```
X              = 00000000000000000000000001100100  100
Even bits set  = 01010101010101010101010101110101  1431655797
Divided by 8   = 00001010101010101010101010101110  178956974
Halves swapped = 10101010101011100000101010101010  2863532714
```

## Сборка

Платформа **x86**, Ctrl+F5. MASM32 SDK не нужен, это обычный проект C++.

Вставки `__asm` компилятор принимает только под x86.
