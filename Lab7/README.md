# Лабораторная работа № 7

Подпрограммы. По методичке (стр. 29) нужно выполнить задание лабораторной
работы № 5 в среде masm32.

Вариант 5: с клавиатуры вводится строка S из букв и цифр; из букв строки S
сформировать строку S1, из цифр — S2.

## Отличие от лабы 5

Там обработка была ассемблерной вставкой в C++. Здесь это процедура
`Split` на чистом ассемблере, вызываемая директивой `Invoke`.

```asm
Split PROTO :DWORD, :DWORD, :DWORD
...
    Invoke Split, addr s, addr s1, addr s2
...
Split PROC USES ebx esi edi src:DWORD, letters:DWORD, digits:DWORD
```

| Элемент | Назначение |
|---|---|
| `PROTO` | объявление процедуры до вызова, нужно для `Invoke` |
| `PROC` / `ENDP` | границы тела процедуры |
| `USES ebx esi edi` | ассемблер сам вставит `push` в начало и `pop` в конец |
| `src:DWORD, ...` | именованные параметры, доступны внутри по имени |
| `ret` | возврат; при `stdcall` ассемблер сам ставит `ret 12` |

Параметры передаются **по ссылке** — в процедуру идут три адреса, а не
содержимое строк. Для строк иначе и нельзя: по значению пришлось бы
копировать все 100 байт.

## Алгоритм

| Регистр | Назначение |
|---|---|
| `ESI` | текущий символ исходной строки, `lodsb` |
| `EDI` | позиция в S1, `stosb` |
| `EBX` | позиция в S2 |
| `AL` | прочитанный символ |

Символ классифицируется сравнением с границами ASCII: `'0'..'9'` — цифра,
`'A'..'Z'` и `'a'..'z'` — буква, остальное пропускается. Цикл идёт до
нулевого байта, в конце обе строки закрываются нулём.

## Сборка

Платформа **x86**, Ctrl+F5. Нужен MASM32 SDK в `C:\masm32`.
