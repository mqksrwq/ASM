# Лабораторная работа № 4

Вариант 5: из массива целых положительных чисел создать новый массив,
в котором числа расположены в обратном порядке.

Обработка массива — ассемблерная вставка `__asm` в функции `get_result`,
ввод и вывод на C++.

## Алгоритм

| Регистр | Назначение |
|---|---|
| `ESI` | адрес текущего элемента исходного массива |
| `EDI` | адрес начала нового массива |
| `EDX` | смещение элемента в новом массиве, в байтах |
| `ECX` | счётчик цикла, `n` повторений |
| `EAX` | переносимое значение |

```asm
        mov edx, ecx
        dec edx
        shl edx, 2

    lp:
        mov eax, [esi]
        mov [edi + edx], eax
        add esi, 4
        sub edx, 4
        loop lp
```

`ESI` идёт вперёд от начала массива, `EDX` — назад от последнего элемента.
Элемент типа `int` занимает 4 байта, поэтому шаг равен 4, а начальное
смещение равно `(n - 1) * 4`. Умножение на 4 сделано сдвигом `shl edx, 2`.

`ECX` под счётчик и команда `loop` работают, потому что внутри вставки нет
вызовов функций.

## Ввод

Длина массива вводится с клавиатуры, после чего программа запрашивает
элементы и печатает результат. Затем цикл повторяется. Пустая строка
вместо длины завершает программу.

Ввод идёт через `getline`, а не через `cin >>`: оператор `>>` пропускает
переводы строк и пустую строку просто не заметит. Строка превращается
в число функцией `atoi`.

Массивы выделяются через `new` под введённую длину и освобождаются
в конце каждого прохода.

## Сборка

Платформа **x86**, Ctrl+F5. MASM32 SDK не нужен, это обычный проект C++.

Вставки `__asm` компилятор принимает только под x86, под x64 и ARM64 они
не поддерживаются.
