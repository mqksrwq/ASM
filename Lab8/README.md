# Лабораторная работа № 8

Макросы. По методичке (стр. 31) нужно выполнить задание лабораторной
работы № 6 в среде masm32.

Вариант 5: дано X (DWORD). Чётные разряды задать единицами, полученное
значение разделить на 8, поменять местами правую и левую части.

## Макросы

```asm
SetEven MACRO var
    or var, 55555555h
ENDM

Div8 MACRO var
    shr var, 3
ENDM

SwapHalves MACRO var
    ror var, 16
ENDM
```

Каждый шаг задания получил имя, и основная программа читается как условие:

```asm
    ShowBin xv, m1
    SetEven xv
    ShowBin xv, m2
    Div8 xv
    ShowBin xv, m3
    SwapHalves xv
    ShowBin xv, m4
```

`var` — формальный параметр, при вызове на его место подставляется текст
`xv`. Макрос не вызывается как процедура: `CALL` не используется, команды
подставляются в код прямо на этапе ассемблирования.

## Макрос с меткой

```asm
ShowBin MACRO var, caption
    LOCAL BinLoop
    ...
BinLoop:
    shl edx, 1
    mov al, '0'
    adc al, 0
    ...
    loop BinLoop
ENDM
```

`LOCAL BinLoop` обязателен: макрос вызывается четыре раза, и без этой
директивы метка `BinLoop` определилась бы четырежды — ошибка дублирования.
`LOCAL` заставляет ассемблер подставлять уникальное имя при каждом вызове
и должна стоять первой строкой макроопределения.

Сам вывод: `shl` выталкивает старший бит в флаг переноса, `adc al, 0`
превращает его в символ `'0'` или `'1'`, цикл повторяется 32 раза.

## Пример

Для X = 100:

```
X              = 00000000000000000000000001100100
Even bits set  = 01010101010101010101010101110101
Divided by 8   = 00001010101010101010101010101110
Halves swapped = 10101010101011100000101010101010
```

## Сборка

Платформа **x86**, Ctrl+F5. Нужен MASM32 SDK в `C:\masm32`.
